# ❄️🔥 FrostAir — демо-сайт климатических систем

Демо-лендинг продажи кондиционеров с «живым» интерактивным кондиционером: кнопка на самом устройстве переключает режим охлаждения/обогрева, и вместе с ним меняется тема всей страницы.

🔗 [Посмотреть онлайн](https://hoadf.github.io/FrostAir/)
💾 [Исходный код](https://github.com/hoadf/frostair)

---

## 💡 О проекте

Главная идея — кондиционер не просто картинка, а элемент управления всей страницей:
- клик по кнопке Power на кондиционере переключает режим «холодно / тепло»;
- при похолодании — холодная цветовая палитра и лёгкая «изморозь» по краям экрана;
- при нагреве — тёплая палитра и мерцающий поток воздуха по краям;
- выбранный режим запоминается (localStorage) и восстанавливается при следующем визите;
- компактный виджет температуры закреплён вверху экрана и виден всегда, независимо от прокрутки страницы;
- иконки моделей в каталоге — собственные inline-SVG (без ссылок на сторонние сайты производителей, поэтому ничего не может «отвалиться»).

---

## 🧩 Технологии

- **HTML5** — структура страницы
- **CSS3** — тема, анимации краёв экрана, адаптивность
- **JavaScript (Vanilla)** — переключение темы, рендер каталога, localStorage
